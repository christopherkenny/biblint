Formatting

biblint format writes a canonical representation of the BibTeX it understands. By default it changes layout, entry-type spelling, and field-name spelling only.

Default shape

Input:

@ARTICLE{Smith2024,
author={Smith, John},
title={A Study},
year=2024
}

Default output:

@article{Smith2024,
  author = {Smith, John},
  title = {A Study},
  year = 2024
}

The default does not align equals signs, sort entries or fields, add braces, change values, or remove duplicate and empty fields. It separates entries with a blank line.

Layout and ordering

[format]
indent = 2                 # a space count, or "tab"
align = false              # or a field-name column number
blank-lines = true
trailing-commas = true
wrap = 80                  # false disables wrapping
sort = ["key"]
sort-fields = ["title", "author", "year"]

align = false disables alignment. sort = true uses key order, and sort-fields = true uses biblint’s built-in field order. Lists provide an explicit order.

Value transforms

These settings are opt-in because they alter value spelling or representation:

Setting Effect
curly Enclose values in braces.
numeric Render numeric values as bare literals.
months Normalize recognized month names.
format-page-ranges Normalize page ranges.
escape / unescape Convert supported text between Unicode and LaTeX.
encode-urls Encode URL underscores.
strip-enclosing-braces Remove one outer brace group.
enclosing-braces / remove-braces Select fields whose brace depth changes.
drop-all-caps Convert all-caps values to title case.
wrap Wrap long values at a configured width.
lowercase Lowercase entry types and field names. Enabled by default.

The escape table is package-independent. Unconvertible characters are preserved and reported by unsupported_escape.

Cleanup and semantic transforms

[format]
remove-empty-fields = true
remove-duplicate-fields = true
omit = ["abstract"]
strip-comments = true
tidy-comments = true
max-authors = 3
generate-keys = true
duplicate-kinds = ["doi", "citation"]
merge = "combine"

These settings can remove information, change author lists, generate keys, or merge entries. merge accepts first, last, combine, and overwrite. By default it considers DOI, citation, and abstract duplicates. Add key to duplicate-kinds to include key duplicates.

generate-keys uses the same formula evaluator as the key_format rule. See Citekey generation for a Better BibTeX syntax subset.

Fix safety

check --format --fix applies safe formatting edits when formatting is explicitly enabled. For a formatting-only policy check, use biblint format references.bib --check. Transforms that can change content or identity require:

biblint check references.bib --format --fix --unsafe-fixes

The standalone format command applies the configured profile directly.

Preserved source

Comments, special entries, and unstructured source are retained unless a configured transform targets them. Unstructured source is reported as unsupported_construct rather than discarded.
